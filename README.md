# Football Team Logo Classification (CNN)

A computer vision project that trains a Convolutional Neural Network (CNN) to classify football team logos from images.  
This repository is implemented in **Jupyter Notebook** and demonstrates an end-to-end image classification workflow: data preparation, model training, and evaluation.

---

## Project Overview

**Goal:** Given an input image of a football team logo, predict which team it belongs to (multi-class image classification).

Typical steps included in the notebook:
- Load and organize the dataset
- Preprocess images (resize/normalize)
- (Optional) Data augmentation to improve generalization
- Build and train a CNN model
- Evaluate performance (accuracy, loss curves, confusion matrix, sample predictions)

---

## Tech Stack

- **Python**
- **Jupyter Notebook**
- Deep Learning with **CNNs** (commonly via TensorFlow/Keras or PyTorch)
